# Restricted Species — Kenya

A reproducible R project cataloguing all laws, regulations, institutions, and species lists governing **restricted, prohibited, and protected species** in Kenya.

## Project Structure

```
Restricted Species/
├── Restricted Species.Rproj   # RStudio project file
├── .Rprofile                  # Activates renv on project open
├── renv.lock                  # Package snapshot for reproducibility
├── renv/activate.R            # renv activation script
├── README.md                  # This file
│
├── R/
│   ├── 01_scrape_laws.R       # Load & clean Kenyan species laws
│   ├── 02_institutions.R      # Map regulatory institutions to laws
│   ├── 03_species_listing.R   # Compile comprehensive species master list
│   └── 04_merge_and_export.R  # Merge all data; export CSVs and HTML tables
│
├── data/
│   ├── raw/
│   │   ├── laws.csv           # Pre-compiled laws dataset (12 laws/regulations)
│   │   ├── institutions.csv   # Regulatory institutions (14 bodies)
│   │   └── species_raw.csv    # Species records (~100 species)
│   └── processed/             # Generated by R scripts (gitignore-able)
│
├── output/
│   └── tables/                # CSV exports and HTML formatted tables
│
└── docs/
    ├── restricted_species_kenya.Rmd   # Main analysis report
    ├── style.css                      # Custom HTML report styling
    └── references.bib                 # BibTeX bibliography
```

## Quick Start

### 1. Prerequisites

- R ≥ 4.3.0
- RStudio (recommended) or any R environment

### 2. Restore the package library

```r
# Install renv if not already installed
install.packages("renv")

# Restore packages from renv.lock
renv::restore()
```

### 3. Run the data pipeline

Scripts are designed to run in order:

```r
source("R/01_scrape_laws.R")
source("R/02_institutions.R")
source("R/03_species_listing.R")
source("R/04_merge_and_export.R")
```

Or run them all at once:

```r
purrr::walk(list.files("R", full.names = TRUE), source)
```

### 4. Render the report

```r
rmarkdown::render("docs/restricted_species_kenya.Rmd",
                  output_dir = "output/reports")
```

The rendered HTML report will open automatically in your browser.

## Coverage

### Laws and Regulations (12 instruments)

| Law | Year | Sector |
|-----|------|--------|
| Wildlife Conservation and Management Act | 2013 | Wildlife |
| Environmental Management and Co-ordination Act (EMCA) | 1999 | Environment |
| Fisheries Management and Development Act | 2016 | Fisheries |
| Forest Conservation and Management Act | 2016 | Forestry |
| Seeds and Plant Varieties Act (Cap. 326) | 1972 | Plant Health |
| Plant Protection Act (Cap. 324) | 1937 | Plant Health |
| Biosafety Act | 2009 | Biosafety |
| CITES (via L.N. 241/2017 & 242/2017) | 1963/2017 | Wildlife |
| Kenya Maritime Authority Act | 2006 | Marine |
| National Museums and Heritage Act | 2006 | Heritage |
| Prevention of Organised Crime Act | 2010 | Criminal |
| Proceeds of Crime and Anti-Money Laundering Act | 2009 | Criminal |

### Institutions (14 bodies)

KWS · KFS · NEMA · KEPHIS · NBA · KeFS · KMA · KRA-Customs · KEFRI · KMFRI · KWCA · NMK · NETFUND · DVS

### Species (~100 representative species)

Covers all major taxonomic groups:

- **Mammalia** — elephant, rhinos, big cats, pangolins, cetaceans, dugong, primates
- **Aves** — cranes, vultures, raptors, endemic passerines (Taita Hills, Arabuko-Sokoke)
- **Reptilia** — all 5 sea turtle species, crocodilians, monitors, chameleons, tortoises
- **Amphibia** — highland endemics, Taita Hills frogs
- **Actinopterygii / Chondrichthyes** — Lake Victoria cichlids, whale shark, manta ray
- **Bivalvia / Gastropoda** — giant clams, marine invertebrates
- **Plantae** — sandalwood, African cherry, cycads, African violets, aloes, invasive plants

## Notes

- The WCMA 2013 Sixth Schedule lists **245 nationally threatened species** — this project includes a representative subset. Contributors are welcome to expand the species dataset in `data/raw/species_raw.csv`.
- Protected tree species under the FCMA 2016 are gazetted by Cabinet Secretary orders; consult KFS directly for the current list.
- CITES appendix statuses reflect CoP19 (2022) decisions. Always verify current listings at [checklist.cites.org](https://checklist.cites.org).
- A new Wildlife Conservation and Management Bill (2025) to repeal and replace WCMA 2013 is under development — monitor [Kenya Law](https://new.kenyalaw.org) for updates.
